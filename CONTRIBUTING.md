# Contributing

Thank you for helping improve Noteware Admin Tables.

## Before opening a pull request

- Discuss large changes in an issue first.
- Work from a focused branch.
- Add or update tests for behavior changes.
- Run the documented local checks.
- Update user and developer documentation.
- Keep code, assets, and dependencies compatible with GPL-2.0-or-later.
- Confirm that the contribution is original or that every reused part has a compatible, documented license.
- Do not include private site data, credentials, or commercial plugin code.

Pull requests must explain the user problem, the approach, security and performance effects, test evidence, and any follow-up work.

By contributing, you agree that your contribution is licensed under GPL-2.0-or-later.
